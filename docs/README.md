# Documentation

Everything about Allium Assault that is not the code itself. The three files that stay in the
repository root are the ones a visitor and a tool expect there: [`README.md`](../README.md),
[`CHANGELOG.md`](../CHANGELOG.md) and [`AGENTS.md`](../AGENTS.md).

| Document                                             | What it is                                                                                    |
| ---------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| [`VISION.md`](VISION.md)                             | What the game is meant to be: rules, weapons, settings, the feel it is aiming for             |
| [`ARCHITECTURE.md`](ARCHITECTURE.md)                 | The C4 model, in Mermaid: context, containers, components, and how a frame flows through them |
| [`PERFORMANCE.md`](PERFORMANCE.md)                   | What was measured, how to measure it again, and what was done about it                        |
| [`SOUND.md`](SOUND.md)                               | Every synthesized sound and how it is made — there are no audio files                         |
| [`tasks.md`](tasks.md)                               | Every request ever made, its status, and the version it landed in                             |
| [`review.md`](review.md)                             | The latest code and architecture review, with how each finding was resolved                   |
| [`PLAN.md`](PLAN.md)                                 | The original v2 plan; historical, kept because it explains why the rewrite looks like this    |
| [`touchdisplay-support.md`](touchdisplay-support.md) | A design study for playing the whole game on a touchscreen                                    |
| [`archive/`](archive/)                               | Finished plans and the original research session                                              |

Contributing and security policy live in [`.github/`](../.github/), which is where GitHub looks for
them: [`CONTRIBUTING.md`](../.github/CONTRIBUTING.md) and [`SECURITY.md`](../.github/SECURITY.md).
